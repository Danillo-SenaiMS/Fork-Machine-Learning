# Modelo de Arvore de Decisão (Scikit-Learn)

Este notebook apresenta um modelo de árvore de decisão utilizando a biblioteca Scikit-Learn. O objetivo é demonstrar como construir, treinar e avaliar um modelo de árvore de decisão para classificação.
- Modelos de árvore de decisão do Scikit-Learn todos os valores das variáveis devem ser do tipo numérico, quando não tivermos valores numéricos, devemos fazer a transformação desses valores em numéricos. (Variáveis Dummies)

# Tipos de Aprendizados de Máquina
- Supervisionado: Quando temos os dados de entrada e saída (rótulos) e o modelo aprende a partir desses dados para fazer previsões em novos dados.
  - Classificação / Regressão
- Não Supervisionado: Quando temos apenas os dados de entrada e o modelo tenta encontrar padrões ou agrupamentos nos dados sem rótulos.
  - Clustering / Redução de Dimensionalidade
- Semi-Supervisionado: Combina elementos de aprendizado supervisionado e não supervisionado, onde alguns dados têm rótulos e outros não.
  - Classificação / Clustering
- Reforço: O modelo aprende a tomar decisões através de interações com um ambiente, recebendo recompensas ou punições com base em suas ações.
  - Jogos / Robótica
